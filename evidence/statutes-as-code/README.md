# Statutes as code, and a model translating them

A first-pass review, read on 2026-11-12, in the shapes of [reader-ergonomics-review](https://github.com/Tewf/reader-ergonomics-review)
v0.1.1. It asks what exists to write a statute as code, whether a legal question is yes/no, whether a model can
translate a statute into logic and back faithfully, and what Lean adds.

- 46 sources: 35 formal and 11 grey. The stopping estimator of
  [ai-augmented-data-gathering](https://github.com/Tewf/ai-augmented-data-gathering) gives a concept coverage of 0.62 on
  the [search log](search-log.csv): a first pass, with a second one listed in the protocol's limits.
- Every figure was read in an abstract or a summary; none was checked in the paper.
